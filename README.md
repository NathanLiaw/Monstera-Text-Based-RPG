# Monstera - A Roguelike RPG Game

Monstera is a text-based roguelike RPG game developed as part of a programming project. In this game, you play as a character in a world filled with pet monsters called Monstera. Collect them, build your party, and embark on an exciting adventure to defeat the ultimate enemy!

## Features

- Explore a vast world with various challenges.

- Collect and train unique pet monsters.

- Engage in battles with diverse enemies.

- Progress through the story to uncover secrets and face the ultimate foe.

# Prerequisites

To set up and run this project, ensure the following:

1. C++ 17 or Above

  - Make sure your compiler supports C++17 or higher.

  - Check your C++ version in Visual Studio by navigating to:

    - Project Properties > Configuration Properties > C/C++ > Language > C++ Language Standard.

  - Set it to ISO C++17 Standard (/std:c++17).

2. Latest SFML Library

  - Download the latest version of SFML from the official website.

  - Ensure you download the version that matches your compiler and system architecture (e.g., 64-bit).
